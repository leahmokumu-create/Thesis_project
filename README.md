Data

The project uses different datasets, including:
  GPCC precipitation data,
  HadISST sea-surface temperature data, 
  AMIP model simulations and 
  CMIP6 model simulations

The main analysis period is long rains season from March to May for the period 1981-2014 although period from 1950-2020 was also investigated

Major packages used include:

  numpy, pandas, xarray, dask, scipy, statsmodels, matplotlib, cartopy, xesmf

Before running the scripts, check:

  config.py

The file contains paths to the observational data, AMIP simulations, CMIP6 simulations, output folders, analysis periods, and geographic regions.
